# 💱 Currency Converter

A simple currency converter built using React, Vite, and Tailwind CSS.

## Features

- Convert between multiple currencies
- Real-time exchange rates fetched from an external API
- Swap currencies with one click
- Responsive user interface
- Custom React Hook for API data fetching

## Technologies Used

- React
- Vite
- Tailwind CSS
- JavaScript

## Getting Started

```bash
npm install
npm run dev
